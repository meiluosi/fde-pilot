# 常见偏差与对策

| 偏差 | 表现 | 对策 |
|---|---|---|
| 自选高手 | 自愿参加者是最熟练、最积极的人 | 分层指定参与者；分别报告自愿/非自愿；写明代表性限制 |
| 新奇效应 | 刚上线时使用率高、反馈好，之后衰减 | 学习期单列；看稳定窗口；用使用衰减曲线判断 |
| 观察者效应 | 被观察时更认真，节时被高估 | 用系统日志计时而非自报；尽量不改变工作方式 |
| 摘樱桃 | 只统计顺利的案件，难例被剔除 | 适格案件定义事前登记；剔除需记录原因，难例单列 |
| 只看采用 | 活跃用户多，被当成业务改善 | 采用与业务效果分轴判定；业务轴必须有对照或配对证据 |
| 忽略复核成本 | 准确率提升，但复核和纠错时间增加 | 复核/纠错时间计入端到端工时 |
| 混杂因素 | 季节、案型、人员变化与试点同时发生 | 记录混杂；优先同期对照；无法控制就只报相关 |
| 样本不独立 | 同一人、同一模板的案件被当作独立样本 | 按人/模板聚类汇总；报告有效样本量 |
| 事后新增指标 | 结果不佳时换一个“好看”的指标 | 事前登记；事后指标只作探索性发现 |
| 平均值掩盖风险 | 平均准确率高，严重漏检仍存在 | 护栏层单列严重错误；用专项样本；零观察不等于零风险 |
| 转述当实测 | “大家都说省时间”当作节时证据 | 访谈只作线索，写“具体言语”；节时用日志或计时 |
| 归因过度 | 同期别的改进（培训、人员）被算在试点头上 | 写出其他可能原因；无对照则不宣称效果 |
| 政治阻力被忽略 | 一线担心被用于考核，表面配合、实际绕开 | 事前书面约定数据用途；监控绕过行为；单列阻力 |
