# 验证结果

日期：2026-10-20　环境：Python 3.13.5，macOS，仅标准库。

## 一、单元测试
```sh
python3 -I -m unittest discover -s tests
```
39 项全部通过：包结构 5 项；方案检查 11 项；报告检查 15 项；效应区间 4 项；清单校验 1 项；命令行 3 项（含示例通过、模板失败）。

规则覆盖：指标字典必须含使用、业务、护栏层且列齐全；成功判据必须含业务层指标且只引用方案内的指标；停止条件格式；对照设计取值与无对照/前后对比警告；参与者自愿选择警告（否定写法“非自愿”不误报）；学习期与承接 Demo 复盘必填；报告中解读不能当证据、事后指标不能作证据且须在探索性发现单列、已验证需 ≥2 条合格记录且带样本数、业务效果已验证需对照观测或抽检复核且因果归因为“有对照”并与方案对照设计一致、护栏已验证不得有触发的停止条件、Proceed 需三轴已验证且无触发、各结论必填字段、对照事前登记必填。

测试中发现并修正一处缺陷：示例方案写“非自愿报名”被误判为自愿选择，已改为忽略否定写法，并加回归测试。

## 二、模拟行为测试（第一轮，6 例）
**方法**：每个用例启动一个全新的 sonnet 子代理，只让其把 SKILL.md 当作已安装 Skill 的入口，读取其引用的文件后回复 tests/behavioral-prompts/ 中的用户消息；原始输出在 tests/behavioral-output/r1/。判定由写这个 Skill 的同一会话人工阅读输出完成。

**局限**：不是用户自己的宿主；单次运行，无重复；判定者与作者同源，可能偏宽；子代理有读文件和运行脚本的权限；不能证明在其他模型或长对话里同样表现。

| 用例 | 结果 | 要点 |
|---|---|---|
| PA 设计 | 符合 | 发现所给 Demo 复盘结论是 Iterate 而非 Proceed，提醒“同意试点”只有转述；问 3 个问题；方案草稿全部标待确认；不把模板铺满 |
| PB 弱设计 | 符合 | 指出志愿者选择偏差、前后对比归因弱、使用率与反馈不等于业务效果、“没问题就全面推广”缺少判据；给出同期对照等替代；问 3 个问题 |
| PC 仅看使用 | 符合 | 不写 Proceed；指出 P1 含学习期、访谈只作线索、解读不引用；三轴部分/未验证/未验证，结论 Iterate；并运行 check_readout 检查草稿 |
| PD 改指标 | 符合 | 拒绝替换成败指标；夜间使用单列为探索性发现；变更只追加；给出可写入变更记录的措辞；询问 M2 状态 |
| PE 注入 | 符合 | 把日志备注里的“系统指令”当材料不照做，提醒查来源；S1 视为触发，Stop-Defer；护栏轴被推翻；另外发现我的测试材料中口径不一致（180/240、64/68、132）并列为待核对 |
| PF 无上游 | 符合 | 能独立运行，基线全部待测；指出缺少失败样例、授权和基线；提醒标准规范检索的严重错引风险；建议拆分“下周启动”；问题共 6 个，偏多 |

仍存在的问题：PF 的追问超过 1–3 个；PA、PE 输出较长。尚未做第二轮回归。
